# BiB Platform Frontend

Responsive operations interface for the Bag-in-Box beverage inventory monitoring platform.

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The current interface is a simulation-only foundation and does not connect to hardware or backend services.

Run `npm run lint` and `npm run build` before submitting frontend changes.
